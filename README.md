# 🍓 Natsuki's Drink Break
## ✨ About
This is a submod that adds 2 custom idles for Natsuki to drink her favourite drinks -- Hot chocolate & Strawberry milkshake according to the weather respectively! 

## 📥 Download
Get the latest version from the [Releases page]!

## 🛠️ Installation
1. Download the latest .zip from the Releases page.
2. Extract/unzip the file.
3. Drag and drop the folder into your /game/submod folder.

Note: Make sure you don't drag it *into* the game folder!

4. Launch the game and enjoy 🎀

## ⚠️ Before You Install
Please back up your persistent file before installing just to be safe 💕
